### Programs I Created

Here are the three Java programs I wrote, compiled, and tested:

1. **`SimpleCalculator.java`** - This program asks for two numbers and calculates their sum, difference, product, and quotient.
2. **`AverageCalculator.java`** - This program asks for a student's name and three test scores, then calculates and displays the total and average.
3. **`ItemCost.java`** - This program asks for an item's name, quantity, and price, then calculates and displays the total cost.

### How to Run My Code

To run these programs, open a terminal inside the `cos201 assignment` folder and use the following commands:

**To run the Simple Calculator:**

- Type `javac SimpleCalculator.java` to compile it.
- Type `java SimpleCalculator` to run it.

**To run the Average Calculator:**

- Type `javac AverageCalculator.java` to compile it.
- Type `java AverageCalculator` to run it.

**To run the Item Cost program:**

- Type `javac ItemCost.java` to compile it.
- Type `java ItemCost` to run it.
